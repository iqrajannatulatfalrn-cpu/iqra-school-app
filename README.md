# Iqra School Management App

School management system for **Iqra Jannat-ul-Atfal School & Academy, Rasool Nagar** (District Wazirabad, Punjab).

A single-page web app (PWA) in Urdu (RTL) that works **online and offline**:

- Dashboard (students, collection, dues, expenses, savings)
- Students register with sibling-discount note
- Fees: payment entry, monthly register, absence-fine record kept separate (Rs 100/day, unreported absence only)
- Attendance (present / leave with notice / absent without notice)
- Teachers & salaries, Expenses
- Results with grades and printable result cards
- Admissions plan for January 2027 (inquiry register + checklist)
- Printable templates: fee voucher, fee receipt, result card, admission form, leave slip, parent notice
- Backup: export/import JSON (data stays on the device)

Data is stored locally in the browser (localStorage). The seed data is **demo data only** (names marked ڈیمو); the school's live record remains its Excel workbook until migration is approved.

## Use
Open the GitHub Pages site for this repository, then on the phone choose **Install app / Add to Home screen**. After the first load it works offline.
